Cómo instalar

  1. Toca Descargar arriba.
  2. Abre el archivo descargado (reno-rd.apk).
  3. Si aparece un aviso, activa “Permitir de esta fuente” y vuelve.
  4. Toca Instalar → Abrir.

Solo Android. En iPhone el archivo .apk no se puede instalar.
